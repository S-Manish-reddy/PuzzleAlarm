⏰ PuzzleAlarm

PuzzleAlarm is an Android alarm clock app that forces users to solve a puzzle to dismiss the alarm, helping them wake up more alert and avoid snoozing.

Instead of turning the alarm off half-asleep, users must actively engage their brain — making it harder to fall back asleep.

---

✨ Features

- ⏰ Reliable alarm scheduling
- 🧩 Puzzle-based alarm dismissal
- 🔊 Loud alarm sound until the puzzle is solved
- 📱 Clean, modern Android UI
- ⚡ Built with modern Android & Gradle tooling

---

🛠 Tech Stack

- Language: Kotlin
- Platform: Android
- UI: Jetpack Compose (Material 3)
- Build System: Gradle (Kotlin DSL)
- IDE: Android Studio

🚀 Getting Started

### Prerequisites
- Android Studio (latest stable)
  
- Android SDK
  
- JDK 17 (recommended)

### Clone the Repository

git clone https://github.com/S-Manish-reddy/PuzzleAlarm.git

cd PuzzleAlarm

### Run the App
- Open the project in Android Studio

- Let Gradle sync complete

- **Run the app on:**
  
  1.An emulator, or
  
  2.A physical Android device

🔒 Permissions Used

- Alarm scheduling (Exact alarms)

- Foreground services (for reliable alarms)

- Audio playback

- **NOTE:**(These two permissions are compulsary from the user)

- Notifications permission

- Battery optimization exemption (recommended: set to Unrestricted for reliable alarms)
